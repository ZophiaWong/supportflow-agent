# Enterprise SSO Setup

Enterprise plan customers can enable SAML SSO after they provide the identity provider metadata URL, entity ID, and administrator contact.

Support should not ask customers to paste secrets into a ticket. If a configuration error blocks login, collect the error message and route the case to identity support.
